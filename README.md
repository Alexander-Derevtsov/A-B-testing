# Анализ результатов A/B-теста новой механики оплаты

## Описание проекта

В рамках проекта проведен анализ результатов A/B-теста новой механики оплаты образовательной платформы.

Цель исследования — определить, влияет ли новая механика оплаты на ключевые продуктовые метрики и стоит ли распространять изменения на всех пользователей.

---

## Бизнес-задача

Команда продукта протестировала новую механику оплаты на части пользователей платформы.

Необходимо:

- оценить влияние изменений на пользовательское поведение;
- проверить статистическую значимость полученных различий;
- принять решение о масштабировании новой механики оплаты.

---

## Используемые данные

Для анализа использовались данные о:

- принадлежности пользователей к контрольной и экспериментальной группам;
- активности пользователей в период эксперимента;
- совершенных платежах;
- дополнительных пользователях, поступивших после начала анализа.

---

## Ход исследования

### 1. Подготовка данных

- объединение источников данных;
- обработка дополнительных данных;
- поиск пропусков и дубликатов.

### 2. Анализ продуктовых метрик

Для контрольной и экспериментальной групп рассчитаны:

- конверсия в оплату;
- ARPU;

### 3. Статистический анализ

Для оценки результатов эксперимента проведена проверка статистических гипотез с использованием соответствующих статистических критериев.

### 4. Интерпретация результатов

Полученные результаты проанализированы с точки зрения их практической значимости для бизнеса.

---

## Основные результаты

- проведено сравнение ключевых метрик контрольной и экспериментальной групп;
- оценена статистическая значимость различий;
- сформулированы выводы о влиянии новой механики оплаты;
- подготовлена рекомендация о дальнейшем внедрении изменений.

---

## Выводы

На основании проведенного анализа определено, оказывает ли новая механика оплаты положительное влияние на ключевые продуктовые показатели и целесообразно ли ее внедрение для всех пользователей платформы.
